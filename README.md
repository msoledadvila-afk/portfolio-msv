# Portfolio · María Soledad Vila

Sitio personal de Sole Vila, Vibe Coder & Arquitecta Digital: desarrollo de aplicaciones web con IA integrada y gestión de contenido para PyMEs y profesionales.

**Estado:** Producción
**Sitio:** [mariasoledadvila.com.ar](https://mariasoledadvila.com.ar)

## Qué muestra

- Servicios de desarrollo a medida y de contenido
- Casos y demos de software con IA para PyMEs (RRHH, estudios contables, operaciones, educación)
- Relación con el Ecosistema PCA™ de [Talento Impulsa](https://talentoimpulsa.com.ar)

## Stack

| Capa | Tecnología |
| --- | --- |
| Frontend | HTML + CSS + JS, archivo único |
| Medios | Imágenes y videos propios (`images/`, `videos/`) |
| SEO | `sitemap.xml`, `robots.txt`, etiquetas canónicas y Open Graph |
| Hosting | Netlify con dominio propio |

## Cómo se construyó

Desarrollado con vibe coding: diseño de la arquitectura y del flujo, construcción asistida por IA y revisión manual de cada entrega. Usa la sub-marca Portfolio del [Design System MSV 2026](https://github.com/msoledadvila-afk/design-system-msv-2026).
